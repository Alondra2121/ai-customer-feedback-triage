AI Customer Feedback Triage Assistant

A lightweight prototype showing how an AI-assisted workflow could turn unstructured customer feedback into a category, urgency level, recommended next action, escalation flag, and draft response.

Public demo note: this version uses transparent rule-based logic so no API key or customer data is sent anywhere. The documented prompt shows how I would connect the workflow to an LLM.
Run the workflow to see the structured triage output.
Workflow
1. CaptureRaw customer feedback enters the workflow.
2. ClassifyIdentify issue type, sentiment and urgency.
3. RouteRecommend the right owner and next action.
4. RespondDraft a concise reply for human review.
5. LearnStore structured fields for trend analysis.
